# WeaveAI Geometry Sandbox v0.2

Use the same authoritative JSON generated by v0.1.

What changed in v0.2:
- side-by-side BEFORE / AFTER comparison
- explicit "same object mass?" and centroid-shift indicators
- direct field-equality / L2 difference readout when the pair exists in JSON
- overlaid radial histograms
- overlaid Fourier magnitude curves
- band-fraction comparison
- harmonic-k slider that shows the actual `cos(kθ)` and `sin(kθ)` waves
- plain-language interpretation box

Recommended first comparisons:
1. `circle_base` vs `circle_extra_canvas`
2. switch grid-relative → object-relative
3. `circle_base` vs `circle_tight_crop`
4. `circle_base` vs `circle_plus_concentric_ring`

Python remains the scientific source of record. This HTML is a visual debugger / teaching microscope.
